# Repozytorium `ee`

## QML Akademia — aplikacja do nauki (Android + przeglądarka)

Aplikacja do nauki i powtórek z informatyki kwantowej, **kwantowego uczenia maszynowego (QML)** i klasycznego ML: 44 lekcje, 245 fiszek z powtórkami SM‑2, 159 pytań quizowych i interaktywne laboratorium (sfera Blocha, symulator obwodów, trening VQC, kernele kwantowe, parameter‑shift).

- 📦 APK dla Androida: [`release/QML-Akademia-1.0.apk`](release/QML-Akademia-1.0.apk)
- 📖 Opis, instrukcja instalacji i budowania: [`qml-akademia/README.md`](qml-akademia/README.md)
