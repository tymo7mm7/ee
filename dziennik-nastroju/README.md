# Mój Dziennik – dziennik samopoczucia

Aplikacja na Androida (8.0+) do codziennego zapisywania stanu psychicznego, objawów i dolegliwości.

- **Codzienny wpis:** nastrój (5 emotek), energia, poziom lęku 0–10, sen, objawy (lista + własne), leki, notatka oraz „co pomogło / co pogorszyło”. Można uzupełniać także wcześniejsze dni.
- **Dziennik:** pasek ostatnich 7 dni i lista wpisów.
- **Statystyki (7/30/90 dni):** wykresy nastroju i lęku, najczęstsze objawy, związek snu z nastrojem.
- **Raport:** udostępnienie podsumowania 30 dni, np. lekarzowi lub terapeucie.
- **Wsparcie:** numery pomocowe z przyciskiem „Zadzwoń”, ćwiczenie oddechowe, technika uziemienia.
- **Prywatność:** blokada PIN-em; dane tylko na telefonie (kopia w chmurze wyłączona).
- **Przypomnienie:** codzienne powiadomienie o wybranej godzinie, jeśli brak wpisu.

Aplikacja nie zastępuje porady lekarza ani psychoterapeuty.

## Pobranie APK
Zakładka **Releases** na GitHubie, wydanie `dziennik-nastroju-N`, plik `MojDziennik.apk`.

> zastąp go prywatnym kluczem trzymanym w GitHub Secrets.
